## Public-edition model policy

The original model repository used a multi-file Archi/coArchi-style working structure and also contained course navigation elements and assignment tracking objects. Publishing that working tree verbatim would mix architectural content with educational scaffolding.

For that reason, this public edition exposes a documented inventory and portfolio walkthrough rather than copying the original model repository wholesale.
