# Supporting analysis

The original study included several supporting analytical artifacts in addition to ArchiMate views. They are summarized here rather than published as raw course working files.

## Gap analysis

A baseline-to-target matrix was used to identify architecture deltas and connect them to migration work. The analysis distinguished retained, changed, introduced and removed elements and became an input to the implementation roadmap.

## Stakeholder analysis

Stakeholders were classified by influence and interest, with communication recommendations linked to the transformation. This work also provided input to the motivation model and readiness assessment.

## Risk assessment

The study identified project risks, mitigation actions, initial exposure and residual exposure. A heat-map representation was used to compare probability and impact and to justify mitigation priorities.

## Functional-role model

A functional-role matrix was created for the target architecture function and adjacent analytics/data responsibilities. It identifies required roles, competency coverage and cases where role combination is feasible.

## Change-readiness assessment

Readiness factors were grouped into assessment domains and evaluated with stakeholder input. The result highlighted strong motivation and investment readiness together with improvement areas related to skills, information security and employee enablement.

The architectural consequence was a recommendation for staged transformation rather than simultaneous rollout of every target-state capability.
